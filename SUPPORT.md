# Support

Use the GitHub issue templates for installer bugs and feature requests. Read
[Troubleshooting](docs/TROUBLESHOOTING.md) first.

This community project can help with:

- option validation and installer behavior;
- Ubuntu package setup performed by this repository;
- reproducible errors in the included script or tests.

Use [Tailscale support](https://tailscale.com/contact/support) for service-side
issues, account administration, tailnet behavior, official client defects, or
billing. Use Ubuntu support channels for general APT, kernel, or systemd issues.

Before opening an issue, remove secrets and include the sanitized diagnostic
details listed in the troubleshooting guide.
