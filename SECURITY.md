# Security policy

## Supported versions

| Version | Security fixes |
| --- | --- |
| Latest release | Supported |
| Older releases | Best effort |

## Reporting a vulnerability

Do not open a public issue for a vulnerability or suspected secret exposure.

Use GitHub's **Report a vulnerability** private reporting feature when it is
enabled for the repository. If it is unavailable, contact the repository owner
privately through the contact method on their GitHub profile and include only a
minimal, sanitized description until a secure channel is established.

Please include:

- affected version and Ubuntu release;
- impact and realistic attack scenario;
- minimal reproduction steps;
- suggested remediation, if known.

Never send a live Tailscale auth key, node key, signed login URL, or unrelated
private logs.

An initial acknowledgment is targeted within seven days. Disclosure timing will
be coordinated after impact and remediation are understood.
